      Cara kerja dashboard & alur S&OP

      Satu file ZM68 menggerakkan semua halaman. Operation cukup mengunggah export terbaru setiap pagi.

      Siklus S&OP di dashboard ini

      1 · Demand reviewSales MTD vs forecast, tren 6 bulan, proyeksi run-rate dan lost sales. 2 · Supply reviewOOS & Low, cek incoming, rekomendasi order hari ini. 3 · Over & no moveRekonsiliasi kelebihan stok: daftar dorong penjualan untuk Sales. 4 · Review mingguanPre-S&OP / executive: kelas A, scorecard dan tren KPI.

      Ritme kerja

      • Harian (pagi), Operation: export ZM68 → klik Perbarui data ZM68 → kirim daftar over/no move ke Sales dan proses Operation order hari ini.
      • Harian, Sales: SKU over jadi prioritas kunjungan & penawaran outlet; follow-up outlet untuk SKU OOS yang sudah ada incoming.
      • Mingguan, Sales + Operation: buka Review mingguan; SKU prioritas = Sales MTD & average tertinggi (kelas A).
      • Bulanan, S&OP: Demand review → Supply review → rekonsiliasi excess/shortage → keputusan executive.

      Cara memperbarui data

      1. Di SAP jalankan ZM68 dan export ke spreadsheet (.xlsx). Format CSV juga bisa.
      2. Klik Perbarui data ZM68 atau tarik file ke halaman ini.
      3. Cek Tanggal data di Pengaturan (otomatis dari tanggal file).
      4. Salin atau unduh daftar aksi untuk dikirim ke tim.

      Berbagi dengan Sales: data yang diunggah pemilik dashboard tersimpan sebagai data bersama dan langsung tampil untuk semua orang yang diberi akses ke link ini, tanpa perlu memuat ulang. Viewer hanya bisa melihat, menyaring dan menyalin; tombol unggah dan pengaturan hanya aktif untuk pemilik/editor. Jika halaman dipasang di web server sendiri (mis.
